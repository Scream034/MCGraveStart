# ✨ Grave Star [RU] + Void Fix

**Grave Star** — это продвинутый датапак для Minecraft, который создает "могилу" (Звезду Смерти) на месте гибели игрока. Он сохраняет инвентарь и опыт, предотвращая их исчезновение.

🚀 **Главная особенность:** Полная защита от выпадения вещей в пустоту (Void Fix).

---

## 📋 Возможности

*   **💾 Сохранение инвентаря:** Все вещи складываются в могилу. Они не исчезнут (деспавн отключен).
*   **🔮 Сохранение опыта:** Датапак точно подсчитывает опыт и сохраняет его (по умолчанию 50% от уровня).
*   **🌌 Void Fix (Защита от Пустоты):**
    *   Если вы упали в бездну (ниже Y=-64), могила **не застрянет там**.
    *   Она автоматически телепортируется на вашу **кровать** (Spawnpoint).
    *   Если кровати нет, она появится на **глобальном спавне** сервера.
*   **🖱️ Удобный сбор:** Просто нажмите **ПКМ** по звезде или тексту, чтобы забрать всё.
*   **🇷🇺 Полная локализация:** Все сообщения и голограммы переведены на русский язык.
*   **🛠️ Совместимость:** Работает без использования макросов (стабильно на 1.20+).

---

## ⚙️ Установка

1.  Скачайте архив с датапаком.
2.  Переместите его в папку с вашим миром:
    *   `C:\Users\Имя\AppData\Roaming\.minecraft\saves\Название_Мира\datapacks\`
3.  Зайдите в мир и пропишите `/reload`.
4.  Если вы увидели приветственное сообщение — всё работает!

## 🔧 Команды для Админа

### Установка глобального спавна для могил
Если у игрока нет кровати (он "бомж") и он умер в пустоте, могила полетит в дефолтную точку (0 100 0). Вы можете изменить эту точку на спавн вашего сервера.

1.  Встаньте в нужное место (например, на спавне).
2.  Пропишите команду:
    ```mcfunction
    /function grave_star:set_spawn
    ```
3.  Теперь все "бездомные" могилы из пустоты будут прилетать сюда.
